SHORTFLIX 편집 단축키

Space                 재생/일시정지
A                     자막 추가
S                     선택 자막 분할 (재생 위치 기준)
I / O                 현재 위치를 선택 자막 시작/끝으로
← / →                 0.1초 이동
Shift + ← / →         1초 이동
Delete / Backspace    선택 자막 삭제
Ctrl/Command + Z      실행 취소
Ctrl/Command + Shift Z 또는 Ctrl/Command + Y   다시 실행
Ctrl/Command + D      선택 자막 복제
Ctrl/Command + S      프로젝트 JSON 저장

문구/숫자 입력 중에는 위 편집 단축키를 실행하지 않습니다.
입력 중 Ctrl/Command + Z는 브라우저 입력 필드의 기본 실행 취소를 사용합니다.
Ctrl/Command + S는 입력 중에도 프로젝트 저장에 사용합니다.
대화상자/변환 작업 중에는 편집 단축키를 실행하지 않습니다.
브라우저나 운영체제가 일부 조합을 우선 처리할 수 있습니다.
