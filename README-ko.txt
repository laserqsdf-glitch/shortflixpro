SHORTFLIX — 수동 자막 편집기 전체 배포본

코드 편집 없이 이 ZIP 전체를 Cloudflare Pages에 업로드하세요.
기존 파일이나 이전 v0.11 함수 ZIP과 섞지 마세요.
새 버전에는 음성 인식 모델 및 ai-worker.js가 필요하지 않습니다.

배포
1. Cloudflare Pages 기존 프로젝트 > 새 배포 / Upload assets
2. 이 ZIP 전체 업로드. 폴더 업로드 화면이면 압축을 풀고 내용 폴더를 올리세요.
3. index.html / _headers가 최상위, ffmpeg-worker.js가 assets 안에 있는지 확인
4. 배포 완료 후 HTTPS 주소에서 새로고침
Node/npm/Vite/API 키/서버 작업 불필요. file:// 더블클릭 실행은 미지원입니다.

포함

사용 순서
1. MP4 선택. 편집용 한글 폰트가 처음에 다운로드됩니다.
2. 원본에서 시작할 시간과 내보낼 길이를 지정합니다. 출력은 최대 30초입니다.
3. 제목을 입력합니다. 실제 폰트의 글자 폭을 Canvas로 측정해 최대 3줄 안에서
   가장 큰 글자 크기로 자동 맞춤합니다. 짧은 제목은 크게, 긴 제목은 작게 맞춥니다.
4. 자막 추가를 누르고 문구/시작/종료를 편집합니다.
5. 영상 미리보기에서 Play/슬라이더/타임라인으로 이동하며 시간과 배치를 확인합니다.
6. 현재→시작 / 현재→끝 버튼으로 재생 위치를 자막 시간에 넣을 수 있습니다.
7. SRT 불러오기 또는 SRT 저장이 가능합니다. 예제 SRT도 포함했습니다.
8. MP4 내보내기를 누르면 제목/수동 자막을 실제 영상에 넣습니다.
9. 결과 MP4와 그 결과에 사용된 SRT를 다운로드합니다.

시간 규칙
자막 시간은 원본 파일 전체 시간이 아니라 선택한 클립의 0초 기준입니다.
예: 원본 60초부터 30초 출력 시 자막 0~3초는 원본 60~63초에 해당합니다.
자막 시작/종료는 클립 길이 안이어야 하며 최소 0.02초 길이입니다.
자막끼리 겹치면 내보내기를 막고 해당 행을 표시합니다.
최대 200개 자막 / 각 200자 / 표시 폭 기준 최대 3줄입니다.
긴 자막은 여러 시간 구간으로 나눠주세요.
SRT를 불러오면 기존 자막을 교체할지 확인합니다. 원본 기준 SRT는 시간을 클립 기준으로
맞춰야 하며 앱이 임의로 시간을 자르거나 바꾸지 않습니다.
영상을 바꾸면 자막이 초기화되므로 먼저 SRT로 저장하세요.
페이지를 닫으면 편집 내용이 사라집니다. 자동 영구 저장은 구현하지 않았습니다.
SRT에는 문장/시간만 저장되며 제목/배경/배치/영상은 포함하지 않습니다.

배치
가로/정사각형: 원본을 자르지 않고 최대 크기로 1080x1920 안에 배치.
위쪽 여백에는 자동 크기 제목, 아래쪽 여백에는 수동 자막.
세로: 제목/자막용 여백을 만들려고 추가 축소하지 않습니다. 영상 위에 직접 표시합니다.
정확한 9:16은 화면 전체를 채우고, 다른 세로 비율은 필요한 최소 여백만 생깁니다.
검정/흰색 배경 선택. 여백 글자는 대비되는 색상, 영상 위는 흰 글자+검정 박스.
미리보기는 CSS, 최종 출력은 libass이므로 박스/줄간격/글꼴 렌더링에 작은 차이가 있을 수 있습니다.

하이라이트
자동 음성 인식/대사 분석/Whisper/WebLLM은 제거했습니다.
구간은 직접 선택합니다. 선택 기능으로 음량 기반 하이라이트 추천 버튼을 제공합니다.
추천은 음성이 아닌 에너지/RMS 기준이며 내용의 중요도나 바이럴 품질을 판단하지 않습니다.
오디오 없는 영상도 수동 구간 내보내기는 가능합니다. 음량 추천 기능에는 오디오 트랙이 필요합니다.

처리 및 제한
FFmpeg 0.12.10 core 직접 워커 브리지. MT 로딩 실패 시 ST 재시도.
폰트/제목/자막은 libass ASS로 렌더링합니다. drawtext 필터에 의존하지 않습니다.
입력: MP4 512MiB / 30분 / 4K 상당 픽셀 수 이하. WORKERFS 불가 시 192MiB 이하 대체.
출력: 1080x1920 / 30fps / H.264·AAC MP4, 최대 30초.
데스크톱 Chrome/Edge, RAM 8GB 이상/16GB 권장. 모바일은 지원하지 않습니다.
렌더링이 느리거나 메모리가 부족할 수 있습니다. 브라우저 탭 충돌/OOM의 완전 복구는 보장하지 않습니다.
제목 최대 100자, 실제 폭 기준 최대 3줄. 글리프 없는 이모지 등은 렌더링되지 않을 수 있습니다.
브라우저가 보고한 영상 표시 크기를 사용하므로 특이한 SAR/회전 메타데이터는 확인이 필요합니다.
렌더링 시작 시 편집 상태를 고정하여 사용합니다. 렌더링 후 편집하면 이전 결과임을 표시합니다.

개인정보/광고
영상은 서버로 전송하지 않습니다. 엔진과 폰트는 CDN에서 자동 다운로드합니다.
이 ZIP에 큰 Wasm 바이너리나 폰트 자체가 포함된 것은 아니며 첫 사용에는 인터넷이 필요합니다.
CDN 다운로드에는 일반 접속 정보가 전달됩니다. 실제 광고/분석 SDK는 없습니다.
광고 패널은 바로 닫을 수 있는 시뮬레이션입니다. 카운트다운은 실제 처리 ETA가 아닙니다.
처리 취소는 별도 버튼으로 가능합니다. 완성 결과 Blob URL은 페이지/다음 결과 생명주기에 정리됩니다.

검증

이 환경에서 실행하지 않았습니다. 완전한 실서비스 검증을 의미하지 않습니다.
짧은 영상으로 시간 편집, 미리보기, SRT 왕복, 취소, MP4 결과를 확인하세요.
