SHORTFLIX Caption Studio V2 — 전체 정적 배포본

이 ZIP 전체를 업로드하세요. 이전 ZIP의 파일과 섞거나 코드를 수정할 필요 없습니다.
빌드/설치/npm/Vite/API 키/백엔드/음성 인식 모델이 없습니다.
스타일/편집기/순수 함수/워커를 정적 파일로 분리하여 관리하지만, 사용자 빌드 과정은 없습니다.

배포
1. Cloudflare Pages 기존 프로젝트 > 새 배포 / Upload assets
2. 이 ZIP 전체를 업로드합니다.
3. 폴더 업로드 화면이면 압축을 풀어 index.html과 _headers가 최상위인 폴더를 올립니다.
4. 배포 완료 후 HTTPS 주소에서 새로고침합니다. 기존 UI가 남으면 강력 새로고침합니다.
index.html / _headers / assets 폴더 구조를 유지하세요. file:// 더블클릭 실행은 지원하지 않습니다.

빠른 시작
1. MP4를 선택합니다. 처음에는 한글 폰트 다운로드를 기다리세요.
2. 원본 시작과 출력 길이(최대 30초)를 지정합니다.
3. 제목을 쓰고 자막을 추가하거나 SRT를 불러옵니다.
4. 미리보기, 숫자 입력, 타임라인 드래그로 위치와 시간을 맞춥니다.
5. MP4 내보내기 후 최종 영상을 확인하고 다운로드합니다.

편집 기능
- 80단계 실행 취소/다시 실행. 텍스트 연속 입력은 짧은 그룹으로 묶습니다.
- 자막 문구, 시작/종료 시간, 현재 위치→시작/끝.
- 자막 삭제, 복제, 현재 재생 위치에서 분할, 다음 자막과 합치기.
- 분할은 마지막 텍스트 커서 위치를 사용하고, 없으면 문구 중간을 사용합니다.
- 타임라인 블록 이동, 양끝 손잡이로 길이 조절. 숫자 입력도 항상 가능합니다.
- 타임라인 1~8배 확대, 스냅 없음/0.05/0.1/0.5초.
- 확대 중 재생 위치 따라가기.
- 선택 자막 반복, 0.1초 이동, 0.5~2배 재생 속도.
- SRT 가져오기/내보내기. 시간은 선택한 클립의 0초 기준입니다.
- 검색, 대소문자 구분 일괄 치환, 전체 자막 시간 일괄 이동, 시간순 정렬.
- 자막 크기, 세로 영상 글자색, 외곽선, 반투명 검정 박스, 굵게.
- 제목은 실제 폰트 폭을 Canvas로 측정하여 최대 3줄에 가장 큰 크기로 맞춥니다.
- 제목/자막 영역이 넘치면 자막은 영역 안에서 크기를 줄이며, 그래도 넘치면 오류를 표시합니다.
- 겹치는 시간/범위 초과/빈 문구/너무 긴 자막은 표시하고 내보내기를 막습니다.
- 선택 구간 파형 분석: FFmpeg로 선택 구간 오디오만 추출해 RMS 파형을 만듭니다.
  음성 인식/대사 분석 기능은 아니며, 오디오 없는 영상은 파형 분석이 실패할 수 있습니다.
  수동 MP4 내보내기는 오디오 없는 영상도 가능합니다.

저장/복원
- 편집 후 약 0.6초 뒤 localStorage에 프로젝트를 임시저장합니다.
- 임시저장은 영상 파일 자체를 포함하지 않습니다. 이 브라우저/출처에서만 유지됩니다.
- 재접속 시 복원 배너에서 복원한 후 원본 MP4를 다시 선택하세요.
- 파일 이름/크기는 원본 재선택을 돕기 위한 정보이지 강력한 동일성 검증은 아닙니다.
- 프로젝트 JSON은 제목/자막/시간/스타일을 저장합니다. 원본 영상은 따로 보관하세요.
- SRT에는 시간과 문구만 저장됩니다. 제목/스타일/원본 영상은 포함하지 않습니다.
- 파형은 프로젝트에 저장되지 않습니다. 구간 변경 시 다시 분석하세요.
- 공용 PC에서는 임시저장 삭제를 누르세요. 현재 화면 내용은 유지되며 다음 편집부터 다시 저장합니다.
- 손상되거나 범위를 벗어난 프로젝트를 복원하지 않도록 검사합니다.
- 작성 중 숫자가 비어 있는 등 유효하지 않은 설정은 저장 전에 고쳐주세요.
- 렌더링 후 편집하면 현재 다운로드 결과가 이전 편집본임을 표시합니다.

화면 규칙
가로/정사각형: 원본 전체를 최대한 크게 중앙 배치. 위 여백 제목, 아래 여백 자막.
세로: 자막용 추가 축소 없이 영상 위에 제목/자막. 9:16은 전체 화면.
다른 세로 비율은 원본 보존에 필요한 최소 여백만 남습니다.
흰 배경은 검정 글자, 검정 배경은 흰 글자. 영상 위에는 선택한 글자색/박스/외곽선.
미리보기는 CSS, 최종 출력은 libass ASS입니다. 줄간격/박스/폰트 렌더링은 다를 수 있으므로
최종 MP4를 확인하세요. 안전영역 참고선은 출력하지 않고 플랫폼별 UI 안전을 보장하지 않습니다.

제한
데스크톱 Chrome/Edge, RAM 8GB 이상/16GB 권장. 모바일 미지원.
입력 MP4 최대 512MiB / 30분 / 4K 상당 픽셀 수.
출력 최대 30초 / 1080x1920 / 30fps / H.264/AAC.
WORKERFS 마운트 미지원 시 192MiB 이하만 메모리 복사합니다.
제목 100자/최대 3줄. 자막 300개, 각 300자/최대 표시 3줄. 최소 길이 0.04초.
세밀한 타임라인 편집은 브라우저 미디어 재생 기준이며 프레임 정확한 전문 NLE는 아닙니다.
워드별 애니메이션, 다중 영상 트랙, 전환 효과, 얼굴 추적, HDR 색관리는 구현하지 않았습니다.
무제한 영상 길이나 전문 편집 앱보다 우수한 성능을 보장하는 제품이 아닙니다.
브라우저 OOM/탭 충돌/드라이버 오류를 완전히 복구할 수 없습니다.

개인정보/엔진
영상은 업로드하지 않습니다. Whisper/LLM 모델도 없습니다.
FFmpeg core 0.12.10과 Noto CJK 폰트를 CDN에서 자동 다운로드합니다.
첫 실행은 인터넷이 필요하며 CDN에는 일반 접속 정보가 전달됩니다.
MT 초기화 실패 시 ST 재시도. 완료/취소 후 워커/임시 Wasm 파일시스템/Blob URL 정리.
실제 광고/추적 SDK 없음. 광고 패널은 즉시 닫을 수 있는 시뮬레이션입니다.
카운트다운은 쇼케이스 애니메이션이며 처리 예상시간이나 강제 시청 시간이 아닙니다.
