SHORTFLIX V3 — 120초 편집 + 사용자 PC 로컬 AI 하이라이트 전체 배포본

이 ZIP 전체를 Cloudflare Pages에 업로드하세요. 이전 파일과 섞지 않아도 됩니다.
index.html부터 정적 모듈/스타일/워커/_headers가 모두 포함되어 있습니다.
Node/npm/Vite/빌드/API 키/서버 처리는 필요 없습니다.

배포
1. Cloudflare Pages 프로젝트 > 새 배포 / Upload assets
2. 이 ZIP 전체를 업로드. 폴더 업로드 화면이면 압축을 푼 폴더 내용을 올립니다.
3. index.html과 _headers가 최상위, 나머지는 assets 안에 있는 구조를 유지합니다.
4. 배포 완료 후 HTTPS 사이트에서 새로고침. file:// 더블클릭 실행은 지원하지 않습니다.

두 모드
[직접 편집]
MP4 선택 -> 원본 시작/출력 길이 지정 -> 제목/수동 자막 편집 -> 최대 120초 MP4.
[로컬 AI 하이라이트]
긴 MP4 선택(또는 편집기 원본 사용) -> 목표 길이/언어/중급 모델 선택 -> 분석 ->
후보 미리보기 -> 시작/종료 조정 -> 편집기로 보내기 -> 제목/수동 자막 -> MP4.

하이라이트를 편집기로 보낼 때 중간 영상을 다운받아 재업로드하지 않습니다.
원본 File과 선택 시간 범위를 편집기에 연결하고 최종 내보내기에서 자릅니다.
기존 수동 자막이 있으면 초기화 전에 확인합니다. 분석 대사는 자막으로 자동 삽입하지 않습니다.
자막 시간은 선택된 클립의 0초 기준입니다.
예: 원본 200~290초 선택 -> 편집기/SRT 0~90초 -> 최종 원본 구간 200~290초.

AI는 사용자 PC에서 실행
- 오디오 추출: FFmpeg Wasm
- 대사 분석: Xenova/whisper-small, Transformers.js 3.8.1
- 내용 판단: WebLLM 0.2.79의 실제 등록 모델 목록에서 3B~4B급 instruct 양자화 모델 선택
- 고급 선택: 등록된 7B~8B급 instruct 모델. 별도 다운로드/메모리 확인 창 제공
- Qwen 계열 우선, Llama 3.2 계열 다음, 실제 목록/브라우저 shader-f16 조건에 따라 선택
- 실제 사용 모델 ID는 로그와 결과 요약에 표시. 0.5B/1B로 몰래 낮추지 않습니다.
- GPU Whisper 실패 시 같은 Whisper-small을 CPU/WASM으로 재시도
- STT와 LLM은 별도 워커로 차례로 실행 후 종료. 오디오 추출 FFmpeg도 AI 전에 종료
- LLM은 휴리스틱이 좁힌 최대 8개 후보를 하나씩 평가하여 컨텍스트 초과를 줄임
- 각 후보가 매우 길면 평가 입력에서 시작/끝 대사를 사용하고 중간 생략을 표시
- 대사 중심 분석이며 영상 프레임을 이해하는 시각 AI/얼굴 추적은 구현하지 않았음

대체 모드
대체 추천 허용 시 실패를 로그/결과에 분명히 표시합니다.
1. LLM 성공: 로컬 AI 내용 분석 + 실제 모델 ID
2. 대사 인식만 성공: 대사 기반 휴리스틱 (LLM 미사용)
3. 대사 인식 실패: 음량 기반 추천 (AI 내용 분석 아님)
대체 허용을 끄면 분석 실패 시 오류로 종료하며, 성공한 AI처럼 표시하지 않습니다.
WebGPU가 없으면 LLM은 실행되지 않습니다. CPU Whisper 진행 및 휴리스틱 사용 전 확인합니다.
모델 다운로드는 수 GB가 될 수 있고, 긴 영상 분석은 오래 걸릴 수 있습니다.
16GB RAM 및 충분한 WebGPU/GPU 메모리를 권장하지만 특정 GPU 호환성은 보장하지 않습니다.

비율 규칙 — 두 모드 공통
출력 1080x1920 / 9:16. 원본 화면을 자르지 않고 비율 유지하여 최대 크기로 배치.
- 가로/정사각형: 위아래 검정/흰 여백. 위쪽 제목, 아래쪽 수동 자막.
- 세로: 자막 영역을 만들기 위한 추가 축소 없음. 영상 위에 제목/자막.
- 정확한 9:16: 전체 화면을 채움.
- 다른 세로 비율: 원본 보존에 필요한 최소 여백만 허용.
후보 미리보기는 원본을 object-fit:contain으로 9:16 안에 표시합니다.
후보 자체는 재인코딩하지 않으며 최종 MP4는 FFmpeg scale/pad로 같은 원칙을 적용합니다.
AI가 고르는 것은 시간 구간이지 화면 크롭 영역이 아닙니다.

편집기
수동 자막 추가/삭제/시간 입력, 현재→시작/끝, 분할/합치기/복제.
타임라인 이동/양끝 길이 조절, 1~8배 확대, 시간 스냅, 선택 자막 반복.
80단계 실행 취소/다시 실행, 검색/치환/일괄 시간 이동/시간순 정렬.
SRT 열기/저장, 프로젝트 JSON 저장/열기, 로컬 임시저장과 복원.
제목은 실제 폰트의 글자 폭으로 최대 3줄 안에서 자동 크기 맞춤.
자막도 영역을 넘으면 크기를 줄이고 그래도 안 들어가면 문구 분할을 안내합니다.
Whisper 인식 문장을 자동 자막으로 넣지 않습니다. 사용자가 직접 쓰거나 SRT를 가져옵니다.
V2 프로젝트 JSON도 열 수 있습니다. 해당 V2 브라우저 임시저장도 탐색합니다.
V3에는 V2의 별도 수동 파형 분석 버튼 대신 AI 하이라이트 분석 흐름을 포함했습니다.

저장/개인정보
프로젝트에는 자막/제목/설정/원본 이름·크기만 저장하며 원본 영상 자체는 포함하지 않습니다.
복원 후 원본 MP4를 다시 선택하세요. 이름/크기 일치는 보조 정보일 뿐 강력한 동일성 검증은 아닙니다.
SRT에는 시간/문장만 저장되며 스타일/제목은 없습니다.
AI 분석 대사는 메모리에서 사용하고 프로젝트 임시저장에 포함하지 않습니다.
영상/오디오/대사를 서버 AI로 전송하는 코드는 없습니다. 추론은 브라우저 워커/WebGPU/WASM에서 수행합니다.
모델/엔진/폰트는 CDN에서 자동 다운로드하므로 완전 오프라인 첫 실행은 아닙니다.
ZIP에 수 GB 모델 가중치나 대형 Wasm 바이너리는 포함하지 않았습니다.
CDN 요청에는 일반 접속 정보가 전달됩니다. 실제 광고/분석 SDK는 없습니다.
광고 패널은 바로 닫을 수 있는 시뮬레이션이며 카운트다운은 처리 ETA/강제 시청 시간이 아닙니다.

제한
입력 MP4 최대 512MiB / 30분 / 4K 상당 픽셀 수.
출력 0.1~120초 / H.264/AAC / 30fps. WORKERFS 불가 시 192MiB 이하 메모리 대체.
자막 300개 / 각 300자, 제목 100자. 시간 겹침/범위 초과는 오류를 수정해야 출력 가능.
직접 편집은 오디오 없는 영상도 가능. AI 분석에는 읽을 수 있는 오디오 트랙이 필요.
브라우저 인코딩/AI는 느리고 메모리를 많이 사용합니다. 탭 충돌/OOM 완전 복구는 보장하지 않습니다.
미리보기 CSS와 최종 libass는 글꼴/박스/줄간격이 다를 수 있어 결과 확인이 필요합니다.
프레임 정확 전문 NLE/다중 영상 트랙/전환/워드 애니메이션/HDR 색관리/영상 시각 이해는 미구현.
기술적 120초 출력 설정이며 특정 플랫폼 업로드/수익화/음원 규칙 충족을 보장하지 않습니다.
